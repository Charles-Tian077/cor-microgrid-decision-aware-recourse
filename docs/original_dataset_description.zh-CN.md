# 数据集说明（v2.0，全日期版）

本目录是 SCI 升级包的数据层交付：一份 Excel 总表 + 机器可读副本 + 服务器接入文件。
所有数值来自 2026 年 CUMCM C 题附件 1—4 及其已通过校验的预处理结果，未新增虚构站点/年份，未对实测值做平滑或补造。

## 3. 训练怎么用（关键三条）

1. **只用 10 表训练，目标列只做 y**：`load_kw / pv_kw / net_load_kw / price_yuan_per_kwh` 是观测目标，不得进入特征。
2. **严格按 split 切**：`development`(150d) 训练、`validation`(92d) 选参、`test`(92d) 只评估一次。不要打乱时间顺序，不要用 test 选参。
3. **发布时钟不能回填**：`pv_fc_r06/r12/r18`、`price_fc_r06/r12/r18` 在对应发布时刻前为空（NaN）。日用日前模型只取 r00；日内模型在发布后再取对应列。

服务器示例：

```python
from dataset_loader import load_table
ml = load_table("10_ML训练表_10min")
train, val, test = (ml[ml.split == s] for s in ("development", "validation", "test"))
```

## 4. 口径速查

- Δt = 10 min = 1/6 h；时段 1 = 00:00—00:10，144 = 23:50—24:00；`net = load - pv`，负值表示光伏富余。
- 1 月 = warmup（31 天，只做历史/残差初始化）；可评估期 = 2025-02-01 至 2025-12-31，334 天、48,096 时段。
- 场景 = 11 个因果分位、概率按分位中点（非等概率），是模型输入，**不是独立观测样本**；样本量按真实日算（n=334）。
- 电价单位为元/kWh，且有正下界（模型 0.05，实测最低 0.0076）；负荷/光伏单位 kW。
- 储能：1200—10800 kWh，5000 kW，效率 0.9/0.9；紧急购电 = 交易价 ×5；上调 1.5×、下调罚 0.5×。
- 所有方案统一固定继承的第二问日末 SOC 锚点；不要把 6000 kWh 当每日日初。

## 6. 已知限制（写论文时必须保留）

- 单站点、单年度；时间划分是回顾性验证，不是从未见过的外部测试。
- 滚动控制的储能回放使用当日完整实测序列，费用是**离线匹配比较**结果，不是完整在线 MPC 的效果。
- 场景为共尾保守假设，不是已估计的真实联合分布；场景数增加不保证更准。
- **分位交叉**：第二问的净负荷分位在约 5% 的时段单元存在局部交叉（中位数附近，最大约 0.8 MW）。场景仍按离散结果+概率使用，LP 可行性与精确 CVaR 不受影响，但"每个场景=固定分位"的边际解释需降级；后续可用保序回归重排场景库。该限制已写入 `25_数据质量` 与论文 limitation。
- 合成/压力实验（若有）只能证明机制稳健性，不能计为新实测样本。
